仕様書: 現在作成中

SHORT版 -> main.py<br>
ALL版 -> template.py

注意:
* **使用する場合は、SHORT版とALL版の両方を同じバージョンに揃えること。**
* SHORT版は提出用、ALL版は提出用ではない。
* sortedcontainers は標準モジュールではないため、実行環境で利用可能か確認し、未導入の場合は該当箇所をコメントアウトしてください。
  なお、ローカル環境では pip install sortedcontainers を実行することで使用可能になります。

サポート(バグ報告や改善を受け付けるバージョン)について:
* 最新のバージョンのみがサポート対象になります。報告する際には最新のバージョンでも同様の事象が起こるかを確認してからご報告ください。

自己改善メモ:
* Callableの依存をなるべく無くす。
* 一部関数/問題の組み合わせ次第では型ヒントが邪魔になる場合があるので、その対応をする。
